# Services

- auth: Authentication and authorization
- audit: Audit logs and event tracing
- taxonomy: Canonical skill and domain taxonomy
- documents: Document parsing and storage
- search: Full-text and vector search
- features: Feature extraction and feature store access
- matching: Matching engine (skill, role, domain similarity)
- scoring: Weighted aggregation and rule evaluation
- decision: Ranking, thresholding, and shortlisting
- ranking: Orchestration for matching, scoring, and decision
- bias: Bias monitoring and diversity analysis
- interviews: Tailored interview question generation
- models: Model registry and version tracking
- prompts: Prompt registry and version tracking
- evaluation: Offline evaluation framework
- observability: Metrics, tracing, and logging
- rules: Business rules engine
- workers: Kafka workers for async pipelines
